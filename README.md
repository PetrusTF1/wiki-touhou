# 🌸 Wiki Touhou | Enciclopédia do Touhou Project

> ⚠️ **Aviso:** Este projeto foi desenvolvido com foco em **desktop (PC)**.  
> Pode não estar totalmente otimizado para dispositivos móveis.

---

## 🌌 Sobre o Projeto

A **Wiki Touhou** é uma enciclopédia digital dedicada ao universo de Touhou Project, uma famosa série de jogos do gênero *bullet hell* criada por ZUN.

O objetivo do projeto é centralizar informações de forma **organizada e acessível**, oferecendo uma experiência semelhante a uma wiki moderna, com foco em:

- Clareza  
- Navegação intuitiva  
- Design leve  

---

## 🎯 Visão

Criar uma plataforma que funcione como uma **wiki interativa**, reunindo:

- 📚 Informações sobre personagens  
- 🎮 Dados sobre jogos da franquia  
- 🎵 Conteúdos relacionados às trilhas sonoras  
- 🧩 Estrutura organizada e escalável  

---

## 🌐 Proposta

O projeto busca ser um **Hub informativo**, permitindo:

- Navegação simples entre conteúdos  
- Estrutura clara de páginas  
- Expansão contínua com novos dados  
- Experiência leve e rápida  

---
